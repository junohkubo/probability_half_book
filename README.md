### 第1〜3刷の誤植
（ミスがあり、大変申し訳ありません）
- (2026.10.9)
  - p.191 式(19.11)の下の行を以下のように修正（フォントの都合で 太字やカリグラフィーになっていないかもしれません。$`\mathbb{E}`$は期待値の記号で太字、$`\mathcal{G}`$と$`\mathcal{F}`$はカリグラフィーです）  
    （誤） この確率変数$`\mathbb{E}[X|\mathcal{G}](\omega)`$は$`\mathcal{F}`$-可測ではありませんが，$`\mathcal{G}`$-可測です． 
    （正） この確率変数$`\mathbb{E}[X|\mathcal{G}](\omega)`$は$`\mathcal{G}`$-可測です．
  
    （$`\mathcal{F}`$に含まれる$`\{\mathrm{G}\}`$など、細かいものはこの条件付き期待値では測れません。ただ、$`\mathcal{G}`$に含まれる要素（集合）であれば、$`\mathcal{F}`$にも含まれるので、$`\mathcal{F}`$-可測でした。$`\mathcal{G}\subset \mathcal{F}`$であれば「$`\mathcal{G}`$-可測ならば$`\mathcal{F}`$-可測」です）
